> r01, r02, ... Each answers one of the received project's client questions, or a
> closely related one you justify. Use this header, and put each query's test in
> `../../sql/tests/`, named to match (for example `r01-...` and `tr01-...`).

```sql
-- Test:       sql/tests/tr01-....sql
```
